# 검증 기록 — 2026-10-12

## 결과

실제로 한 사건을 끝까지 플레이할 수 있는 웹 UI 동작을 확인했다. 정식 아트 승인, 실제 음성 품질, 학습 효과와 실물 휴대폰 사용성은 미검증이다.

- Node 22.18.0 / macOS, Playwright 1.64.0.
- Chromium 및 WebKit: 모바일 터치 설정, 360×844 / 390×844 / 430×844 CSS px.
- `npm run check`: JavaScript 구문 확인, 단위 테스트 5개, 정적 빌드 통과.
- 브라우저: 전체 실행에서 12개 통과 후 탭 복원 테스트 2개의 잘못된 대기 조건을 수정해 해당 2개 재실행 통과. 총 14개 시나리오의 최종 결과가 통과다.
- HTTP 미리보기 200 응답. 실행 중 JS 오류를 수집하는 전체 플레이 시나리오에서 오류 없음.

## 수정 및 재확인

첫 실행 직후 `performance.now()`가 450ms 미만일 때 첫 대사 탭도 차단되던 문제를 발견했다. 초기 타이머를 `-Infinity`로 수정해 첫 입력은 즉시 받아들이고 연속 탭만 방지한다. 사건 진입만 한 상태에도 이어하기를 보여 주도록 시작 여부를 기록한다.

브라우저 엔진이 설치되지 않아 초기 실행이 실패했으나 해당 엔진 설치 후 테스트를 수행했다. 탭 충돌 테스트는 동일한 값을 저장하면 storage 이벤트가 발생하지 않는 브라우저 동작과 비동기 패널 열림을 기다리지 않은 테스트 순서를 수정했다. 실제 값 변경 후 충돌 경고와 dialog 표시 후 닫기를 확인하도록 했다.

## 로딩 측정

새 독립 프로토타입이므로 비교할 기존 웹 번들 기준은 없다. 동일한 정적 산출물의 파일별 gzip 합산이며 모바일·데스크톱이 같은 엔트리를 쓴다.

- 초기 JS 및 재귀적 정적 import: 13,446 bytes gzip.
- 전체 JS: 15,302 bytes gzip.
- 공통 CSS: 5,247 bytes gzip.
- 설정/노트/도움 패널 JS는 최초 열 때 동적 import. 패널 CSS는 공통 CSS에 포함된다.
- 이미지·HTML·헤더 전송량은 위 JS/CSS 수치에서 제외. 원본 참고 PNG는 빌드와 초기 로딩에 포함하지 않는다.
- 런타임 서드파티 패키지 없음. Playwright는 개발 테스트 전용.

## 남은 검증

실물 iPhone/Android 터치·브라우저 주소창·가상 키보드와 보조기술 전체 점검, 초급 학습자 사용 관찰, 언어 전문가 문장·발음 검수, 정식 서당개 및 배경 승인, 음성 제작·권리·자연스러움 검수, 반대 방향 교육 콘텐츠는 후속 작업이다. 완전 오프라인·기기 간 동기화·학습 숙달 검증은 제공하지 않는다.

## iPhone 설치 추가 확인 — 2026-10-12

- Capacitor 8.5.3 설치형 래퍼 추가. 웹 런타임 모듈의 정적 import는 기존과 같고 네이티브 컨테이너는 Capacitor를 사용한다.
- Xcode 27.0, 연결된 실물 iPhone 13 / iOS 26.6.2 대상으로 개발 서명 빌드 성공.
- `com.mihye.seodang.prototype` 설치와 프로세스 실행 성공. 기존 운영 앱과 별도 식별자.
- 실기기 캡처에서 서당 체험판 홈·배경·캐릭터·하단 메뉴가 정상 렌더링되는 것을 확인했다. 실기기에서 전체 사건 자동 플레이를 수행했다는 의미는 아니다.
- 웹 에셋 내장, 외부 개발 서버 URL 없음. 노치 여백을 추가했으며 공통 CSS gzip은 5,324 bytes로 변경됐다.
- 구문/단위 테스트 5개/정적 빌드 재검증 통과.

## Claude 협업 UI v2 추가 검증

2026-10-12 전체 UI를 잉크색/등불빛/종이 패널 방향으로 개편했다. 단위 5개, 브라우저 14개 전부 통과했고 최종 대비 보완 후 390px 플레이를 Chromium·WebKit에서 다시 통과했다. Xcode 빌드 및 iPhone 13 갱신 설치·실행 성공. 자세한 변경점, Claude 원문 리뷰, 실기기 캡처, 번들 크기는 `docs/design/REDESIGN.md`에 기록했다.
