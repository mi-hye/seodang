# 난이도별 수업 1개 추가 — 직접 테스트용

한국어·일본어 각각 레벨 2~5에 한 수업씩 추가했습니다. 기존 수업은 유지하며, 새 수업은 각 지도의 마지막 학습 노드입니다. 총 8개 수업, 수업당 학습·연습 3쌍입니다. 레벨 2에는 문장별 말하기 단계도 포함합니다.

| 표시 레벨 | 주제 | 일본어 지도 번호 | 한국어 지도 번호 | 학습 방식 |
|---|---|---:|---:|---|
| 2 | 식당 자리 부탁 | 5 | 5 | 배울 문장 전체 듣기 → 문장별 학습 → 토큰 조립 |
| 3 | 숙소 체크인 | 2 | 2 | 직원 질문과 답을 익힌 뒤 상황에 맞게 대답 |
| 4 | 바뀐 배송 안내 | 3 | 3 | 날짜·기한·수령 조건으로 행동 결정 |
| 5 | 조사 결과 해석 | 2 | 2 | 표본 편향·인과 단정·판단 유보를 구별 |

지도에서 새 노드를 바로 눌러 테스트할 수 있습니다. 오답 뒤 재선택, 중간에 홈으로 나갔다가 이어하기, 완료 후 재학습을 지원합니다. 한국어 레벨 5의 안내·문제·힌트는 한국어이며 단어에는 일본어 대응 표현을 표시합니다. 일본어 레벨 3~5의 한자는 기존 음훈·획순 팝업으로 열립니다.

## 구현과 기록

- 작은 수업 목록·진행 모델은 `src/scenario-state.js`, 본문은 `src/scenario-content.js`, 화면은 `src/scenario.js`에 있습니다. 본문과 화면·CSS는 수업 진입 시에 불러옵니다.
- 저장 키는 언어별 `ko-ja:scenario:1`~`5`, `ja-ko:scenario:1`~`5`. 기존 수업의 ID·정답·저장 기록은 바꾸지 않습니다.
- 지도 완료 수, 언어별 학습 기록, 동의 기반 분석의 시작·오답·진행·완료에 연결했습니다. 답안 문자열은 분석 이벤트에 보내지 않습니다.
- 일본어 VOICEVOX Nemo 男声1, 한국어 Supertonic 3 M1. 새 음성 30개를 합성했습니다. 긴 한국어 지문은 문장별로 합성해 이어 붙입니다. 레벨 2는 0.8배 기본 재생, 그 외는 기존 사용자 재생 속도를 사용합니다.
- 오디오 카탈로그 `2ce53bd56ecd7ab2`: 기존 클립을 유지하고 새 클립 30개·수업별 팩 10개를 추가했습니다. 실제 공개 파일과 SHA-256·크기를 대조했습니다. 앱 업데이트 전의 기존 카탈로그는 그대로 사용할 수 있습니다.
- 한자 42자의 음훈·읽기·획순을 기존 지역 데이터와 고정 버전 KanjiVG에서 추가했습니다. 출처는 기존 설정의 이용안내용 자료에 유지합니다.

## 확인 방법

`prototype`에서 `npm run dev` 후 `http://localhost:4173/playable.html`을 열고 원하는 언어·레벨의 마지막 노드를 선택합니다. 레벨 2의 전체 듣기, 레벨 3의 한자 팝업, 레벨 4~5의 일시정지도 확인해 주세요.

이 변경은 로컬 테스트 버전입니다. 2026-10-19 개발용 빌드를 연결된 아이폰 13에 설치했습니다. 기기가 잠겨 있어 자동 실행은 완료하지 못했습니다. 스토어에는 제출하지 않았습니다. 음성 데이터만 기존 저장소에 추가했고, 모든 음성의 원어민 청취 평가는 별도로 필요합니다.

## 검증

- 상태·콘텐츠·기존 기능 170개 통과: `npm run check`.
- 320px/390px, 글씨 1.2배, 두 언어 10개 수업의 완료·오답·이어하기·가로 넘침·버튼 가로 배치: `npx playwright test scenarios.spec.js` (Chromium/WebKit, 총 40개 통과).
- 음성 30개 실제 다운로드·해시 검사·오프라인 디코딩, 재생·일시정지·이어서 재생: `node scripts/check-scenario-audio-browser.mjs` (Chromium; headless autoplay 허용).
- 전체 음성의 오프라인 디코딩은 WebKit에서도 확인했습니다. WebKit headless의 재생 권한 제한으로 실제 재생 제어 검사는 Chromium에서 수행했습니다. 아이폰 실기기 검사는 아직 진행하지 않았습니다.
- 최초 JS 정적 의존 그래프(모바일/데스크톱 공통): gzip 57,625 → 60,047 bytes. 본문·화면은 초기 그래프에 없습니다. 초기 CSS 15,426 bytes 유지. 정밀 측정 파일은 `artifacts/lesson-expansion-2026-10-19/bundle.json`.
- 한국어 문구 검토: humanize-korean light, 변경률 0.05%, B, 자체검증 6/6, 공통 게이트 OK. 연결어미 뒤 쉼표 3건만 제거했습니다. 예: “보고서를 읽고, 결과로” → “보고서를 읽고 결과로”. 원문·검토본은 `artifacts/lesson-expansion-2026-10-19/copy-review/`에 보관했습니다.
