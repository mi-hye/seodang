# 방향: **「등불 무대」 (Lantern Stage)**

지금 앱은 *크림색 종이 위의 웰니스 읽기 앱*입니다. 바꿀 방향은 **해질녘 극장**입니다. 화면의 바탕은 어두운 밤빛이고, 라스터 배경화가 무대를 채우며, UI는 그 위에 떠 있는 **등불빛 한지 패널**뿐입니다. 종이는 "읽고 배우는 순간"에만 등장합니다. 이 대비 하나로 현재의 cream-on-cream이 즉시 사라집니다.

## 2. 타이포그래피

**번들 폰트 0개.** iPhone 13 WKWebView 래퍼이므로 Apple SD Gothic Neo(KR)와 Hiragino(JP)가 이미 최고 품질로 있습니다. 웹폰트를 넣는 건 용량 대비 이득이 없습니다. 대신 **「서당」 워드마크만 레퍼런스의 붓글씨를 따서 SVG/PNG 로고타입 1장**으로 만드세요. 지금 `AppleMyungjo` → `Georgia` 폴백은 한글에서 완전히 깨집니다.

- 한국어 본문/제목: `-apple-system, "Apple SD Gothic Neo"`. 제목은 **700**, `letter-spacing: -0.02em` (현재 `-1.3px` 고정값은 스케일 업 시 자모가 붙음 → em으로 전환).
- **일본어 2축 규칙** — 이게 핵심 차별점입니다:
  - *학습 대상 문자*(표현 카드, 전이 프롬프트, 노트): `"Hiragino Kaku Gothic ProN"`, **최소 30px**, `letter-spacing:.06em`, `line-height:1.9`. 가나는 자간이 생명입니다.
  - *세계 안의 글씨*(메모 단서, 손님 쪽지): `"Hiragino Mincho ProN"`, 종이 위, 약간 기울임 없이 정자. 명조로 "소품"임을 구분.
- 로마자 독음: `font-feature-settings` 불필요, `opacity:.75`, 13px, 일본어 바로 아래 좌측 정렬.
- 스케일: `--text-scale` 유지하되 1 / 1.15 / 1.3 세 단계. 일본어에는 `max(30px, 30px*scale)` 하한 적용.
- 본문 `line-height:1.7`, 한 줄 최대 **18자** — 390px에서 좌우 패딩 24px면 자동 충족.

## 3. 화면별 레이아웃

전제: 390×844, 상단 안전영역 59px, 하단 홈바 34px. 현재는 topbar 70 + tabs 72 = **화면의 17%가 고정 크롬**입니다. 무대 모드에서는 둘 다 사라집니다.

**start** — 한옥 라스터 full-bleed. 상단 28%에 로고타입(폭 180px, 중앙), 그 아래 한 줄 `일본어 첫걸음 · 한국어 안내` 12px/`--light-400`. 하단에 scrim. CTA는 **amber pill 1개**(높이 56, radius 28, 폭 280). 서당개는 CTA 왼쪽이 아니라 **화면 좌하단 돌계단 위에 앉아** 배경과 합쳐집니다(h 120px, `bottom: calc(env(safe-area-inset-bottom) + 96px)`, `left:20px`). 모션 토글은 우상단 유지하되 `#FFFFFF1F` + blur. `프로토타입 · 임시 아트` 배지는 하단 중앙 10px/`--light-400`, 배경 없음.

**home** — 탭 네비를 **4개 → 3개**로 줄입니다: `이야기 / 노트 / 기록`. 지금의 `내 학습` 숫자 블록(해결 0 or 1, 표현 0~2)은 가짜 통계처럼 보이므로 삭제하고 `기록` 안의 텍스트 한 줄로 흡수합니다. home 자체를 없애고 **이야기 탭이 곧 홈**입니다. 상단 40%는 카페 라스터 히어로(현재 진행 중인 에피소드), 그 위 scrim + `사건 01 · 카페에 남겨진 가방` + 진행 점 6개 + `이어서 하기` amber pill. 그 아래 스크롤로 사건 02/03 목록. "이야기 속으로 한 걸음" 같은 마케팅 카피와 `서두르지 않아도 괜찮아요` 푸터는 전부 삭제 — 현재 접힘선 위를 카피가 다 먹고 버튼이 아래로 밀립니다.

**stories** — home과 같은 스크롤 안의 하위 섹션. 준비 중 2건은 카드가 아니라 **흐릿한 썸네일 없는 1줄 리스트**(번호 + 제목 + `준비 중` 핀). 카드 남발 금지.

**play (intro/solved)** — 무대 모드. 배경 full-bleed, 하단에 **대사 슬랩**: `--stage-700` + `backdrop-filter: blur(16px)` + 상단 1px `--line-dark`, radius 20 0 0 0 없이 상단만 radius 20. 화자 이름은 슬랩 상단 모서리에 amber 작은 탭(좌측 -10px 띄움). 본문 18px, 최소 높이 3줄 고정(현재 `min-height:110px` 유지). 우하단에 깜빡이는 `▸`. **슬랩 전체가 다음 진행 탭 타깃**이고, 450ms 가드는 그대로.

**investigate** — 가장 큰 변화. 카페 라스터가 화면 전체를 채우고(상단 safe-area까지), **가방 3개는 씬 안의 스프라이트**로 바닥 타원 그림자와 함께 놓입니다. 현재처럼 "창문 옆 / 빨간 가방" 한국어 캡션을 가방마다 붙이면 **일본어를 읽을 필요가 사라집니다 — 반드시 제거**하세요. 라벨은 탭한 뒤 선택된 1개에만, 그것도 일본어(`あおい かばん`)로 뜹니다. 선택 상태 = amber 발광 링 + 살짝 1.04 스케일. 하단 슬랩에 질문·피드백·`전달하기` 버튼. 메모 2장은 슬랩 위에 겹친 **작은 종이 모서리 2개**(살짝 회전, `clip-path`로 찢긴 가장자리)로 씬 안에 둡니다. 조사 완료 시 밀랍 도장 느낌의 jade 체크.

**notes (단서 노트/표현 노트)** — 한지 바텀시트. 손잡이 바 → `단서 / 표현` 세그먼트 → 괘선(1px `--hanji-100`, 36px 간격) 위의 행. 카드 테두리 없음. 빈 상태는 "기록 없음" 한 줄 + 작은 서당개 흉상.

**transfer** — 신규 에셋 없이: **같은 카페 라스터를 `scaleX(-1)` + 다른 crop**으로 보여줘 "자리가 달라졌다"를 그림으로 말합니다. CSS 상자로 만든 문/창문 박스는 폐기. 일본어 프롬프트는 상단 한지 띠 1줄에 34px로.

**result (summary)** — 무대 + 약한 jade 발광. 중앙에 세로 두루마리 느낌의 한지 시트, 표현 2개를 `JA 34px / KR 14px` 두 줄씩. 서당개는 시트 우하단에 걸터앉기(128px, 1회 점프 후 정지).

**review** — notes의 표현 탭과 동일 컴포넌트 재사용. 전체 화면 버전만 한지 배경.

**settings / 기록** — 한지 시트 위 44px 이상 리스트 행. 글자 크기는 `가 가 가` 세그먼트이고 **아래에 일본어 샘플이 즉시 커지는 미리보기** 한 줄. 위험 액션(초기화)은 `--rose-400` 텍스트, 하단 분리.

## 4. 인터랙션 디테일

- 탭 피드백: `transform: scale(.97)` 80ms (현재 `translateY(1px)` 교체).
- 대사 타이핑: 22ms/char, 탭하면 즉시 전체 표시, 두 번째 탭에 진행. `[data-motion="off"]` 및 `prefers-reduced-motion`에서 즉시 전체 표시(이미 있는 전역 규칙에 타이핑도 포함되도록 JS에서 분기).
- 진행 표시: 6칸 바 → **등 6개 점**, 채워진 점은 `box-shadow:0 0 8px var(--lamp-200)`.
- 오답 피드백: 화면 흔들기 금지. **등불이 1회 깜빡(opacity 1→.7→1, 220ms)** + 슬랩 피드백 텍스트가 rose 좌측 바로 등장. "틀렸어요"가 아니라 현재 문구(`esc(e.feedback)`) 유지.
- 힌트: 3단계 사다리를 한 번에 다 보여주지 말고 1개씩, 다음 버튼은 `더 보기 (2/3)`.
- 바텀시트: `translateY(16px)→0`, 180ms `cubic-bezier(.2,.8,.2,1)`, backdrop `#15121CA6 + blur(4px)`.
- 포커스 링: `outline: 3px solid var(--lamp-200); outline-offset: 3px` — 어두운 바탕에서 보여야 합니다(현재 `#ac7948`는 다크에서 안 보임).
- 하단 슬랩 패딩: `padding-bottom: max(20px, env(safe-area-inset-bottom))`, 무대 상단 텍스트는 `top: calc(env(safe-area-inset-top) + 8px)`.

## 5. 배경 아트 브리프 (2장만)

공통 스펙: **1170×2532 PNG, 세로, 애니메이션 배경화 스타일**(선화 없는 디지털 유화, 부드러운 붓자국, 공기원근, 따뜻한 역광 — 레퍼런스 `01_start_hanok.png`의 밀도를 유지). **텍스트·간판 글자·UI·사람·말풍선·비네트 금지.** 비네트와 scrim은 CSS가 입힙니다.

**A. 한옥 해질녘 (start)**
북촌풍 골목, 눈높이 약간 낮은 시점. 내려가는 돌계단 길이 화면 하단 중앙에서 소실점으로 빠지고, 좌측에 기와 처마와 불 켜진 등 1개, 우측에 낮은 담장과 가로등. 원경은 노을 하늘과 도시 실루엣의 헤이즈. 상단 좌측 모서리에 꽃가지가 프레임처럼 걸림. 공중에 먼지입자·꽃잎 소량.
색 타깃: 하늘 `#F6C98E → #E89B74 → #8E6E9B`, 그림자 `#4A3A52`, 등불 `#FFD79A`.
구도 제약: **상단 22~38% 구간은 저디테일 하늘**(로고타입 자리), **하단 25%는 평균 밝기 45% 이하**(흰 텍스트·amber 버튼 가독), **좌하단 가로 0~30% / 세로 78~92% 구간에 비어 있는 돌계단 단차 1개**(서당개 착석 자리, 그림자 받을 수 있는 평평한 면).

**B. 카페 실내 (home 히어로 / investigate / transfer)**
오후 늦은 빛. 눈높이 3/4 시점, 좌측 큰 창(따뜻한 역광), 우측 출입문(유리 너머 서늘한 빛), 중앙 안쪽 카운터. 바닥이 화면 하단 40%에 또렷이 보여야 하고 원근 격자가 자연스러울 것. 창가에 빈 원형 테이블 1개와 의자, 문 옆에 빈 의자 1개.
색 타깃: 벽 `#C9A882`, 바닥 `#8A6A4E`, 창광 `#FFE2B0`, 우측 냉광 `#A9BFC9`, 그림자 `#4A362B`.
**필수 제약:** ① 가방·메모·쪽지 등 단서가 될 물체를 **절대 그리지 말 것**. ② 화면 안에 **빨강/파랑 계열 눈에 띄는 물체 금지**(가방 색과 혼동). ③ 세 곳을 비워 둘 것 — 정규화 좌표 **(0.18, 0.64) 창가 바닥**, **(0.36, 0.80) 창가 테이블 아래**, **(0.80, 0.72) 문 옆 바닥**. 각 지점은 어수선하지 않고 바닥 음영이 균일해 스프라이트+타원 그림자를 얹을 수 있어야 함. ④ **좌우 반전해도 어색하지 않게** 강한 비대칭 장식·글자 금지(전이 장면에서 `scaleX(-1)` 재사용).

가방 3개는 새 라스터가 아니라 **SVG를 3/4 시점 + 2단 음영 + 접지 그림자로 다시 그립니다**(현재 정면 평면 SVG는 씬과 광원이 안 맞음). 에셋 추가는 배경 2장뿐입니다.

## 6. 서당개 배치 규칙

슬롯 3개만 허용, 한 화면에 1개:
1. **무대 동반자** — 좌하단, h 120px, 배경 지면에 접지, 대사 슬랩을 12px 겹침. start/solved.
2. **설명자 흉상** — 40px 원형, 한지 시트의 설명 문단 좌측. learn/transfer 힌트.
3. **축하** — 128px, result 중앙 우측.

`서당개 · 임시` 라벨 칩은 **전부 제거**하고, 임시 에셋 고지는 `기록` 탭 하단 한 곳에만 둡니다. 현재는 62/68/105px 세 크기가 섞여 있고 모든 화면에 이름표가 반복됩니다.

## 7. 구현 체크리스트

1. `style.css` 토큰 블록 교체(위 팔레트) → `.shell` 배경 `--stage-800`, `color: var(--light-50)`.
2. `AppleMyungjo`/`Georgia` 전부 제거, 로고타입 이미지로 대체. `letter-spacing` px → em.
3. `b[lang="ja"]` 규칙을 2축(Kaku Gothic 학습용 / Mincho 세계용)으로 분리, 최소 30px 하한.
4. `stage` / `slab` / `sheet` 3개 레이아웃 프리미티브 추가 — 기존 `.page`, `.reading`, `.case-card`, `.paper`, `.stats`는 삭제.
5. `app.js`: 탭 4→3(`stories|notes|records`), `home`을 `stories`에 병합, `my`의 `.stats` 블록 제거(상태 읽기는 유지).
6. `caseCard()` → `episodeHero()` full-bleed 히어로로 재작성.
7. `investigation()`에서 가방 한국어 캡션(`창문 옆` / `빨간 가방`) 제거, 선택 시에만 일본어 라벨 노출.
8. `transferScene()`의 CSS 문/창문 박스 삭제 → 카페 라스터 미러 crop + 절대배치 오브젝트 3개.
9. `ui.js` `bag()` SVG를 3/4 시점·접지 그림자로 재작업, `dog()`의 이름 칩 제거·`size` 인자 추가.
10. 배경 2장 생성 → `media.js` `assets.hanok` / `assets.cafe` 교체(키 유지), 3x 1장 + `image-set` 불필요.
11. 안전영역: 무대 상단 오버레이 `env(safe-area-inset-top)`, 슬랩 하단 `env(safe-area-inset-bottom)`.
12. 모션 off / reduced-motion에서 타이핑·발광·점프 전부 즉시 완료 상태로.
13. 포커스 링 `--lamp-200`으로 교체 후 다크 배경에서 키보드 탐색 1회 검수.

## 8. 현재 가장 큰 문제 5가지

1. **명도 대비가 없음.** `#f7f2e8` 종이 위 `#fffcf5` 카드 + `#dedbcf` 1px 테두리. 전체 화면이 명도 3단계 안에 있어 시선 유도도 깊이도 없습니다.
2. **일본어가 주인공이 아님.** 32px 한국어 명조 제목이 화면을 지배하고 학습 대상인 가나는 카드 안 26px h3입니다. 더 치명적으로 **조사 화면이 가방마다 "창문 옆 / 빨간 가방"을 한국어로 써 줍니다** — 일본어를 안 읽어도 정답이 나옵니다.
3. **아트와 게임 오브젝트가 분리됨.** 평면 SVG 카페는 장식 띠일 뿐이고, 그 위에 흰 카드 가방이 광원·원근·그림자 없이 떠 있어 "장소"가 되지 못합니다.
4. **7개 화면의 리듬이 전부 동일.** `eyebrow → 2줄 h1 → 서당개 → 카드 → 초록 버튼` 반복이고, 마케팅 카피가 접힘선 위를 차지해 유일한 인터랙션이 아래로 밀립니다. 숫자 0/1짜리 통계 블록은 가짜 대시보드로 읽힙니다.
5. **일관성 결손.** 서당개 3가지 크기 + 화면마다 `임시` 라벨, 폰트 폴백 붕괴(명조→Georgia), 녹색이 브랜드·버튼·정답·탭에 동시 사용되어 피드백 신호가 소실, 다크 환경에서 보이지 않는 포커스 링.
