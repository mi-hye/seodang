# 최종 비주얼 리뷰 — Lantern Stage

## 확실히 좋아진 점

**1. 톤의 일관성이 생겼습니다.** 네 화면 모두 딥 잉크 배경 + 앰버 단일 강조색으로 묶여 있고, 강조색이 "지금 누를 것" 하나에만 쓰입니다(시작하기 / 사건 01 시작하기 / 전달하기 / 표현 다시 보기). 보조 동작은 외곽선 카드로 내려가 시선 순서가 명확합니다.

**2. 사진이 UI를 이기지 않습니다.** 스플래시의 골목 사진은 상단 그라데이션으로 "서당" 로고가 뜨고, 홈 카드도 하단 어둠 위에 제목이 얹혀 사진이 분위기 담당, 텍스트가 정보 담당으로 역할이 갈렸습니다. 임시 강아지도 과하지 않게 가장자리에 앉아 있습니다.

**3. 학습 흐름이 화면 구조로 드러납니다.** 조사 화면은 사진(가방 선택) → 단서 카드 2장 → 질문 → 피드백 → 액션으로 위에서 아래로 한 방향이고, 상단 점 인디케이터와 `수집한 단서 2/2`가 진행감을 줍니다. 마무리 화면의 종이 노트는 배경과 대비되는 유일한 밝은 면이라 "오늘 얻은 것"이 한눈에 남습니다. 일본어가 가장 큰 글자, 한국어 뜻이 작게 붙는 위계도 잘 지켜졌습니다.

## 남은 이슈 3가지

**1. 홈 하단 리스트의 잘림 (chromium-home).** 네비게이션 아래로 02·03 카드가 이어지는데, 리스트 블록의 상단 경계가 없어 네비와 콘텐츠가 한 덩어리처럼 보입니다. 리스트 섹션에 제목(예: "다음 이야기")이나 상단 구분선을 주어 네비와 분리해 주세요. 스크롤 동작 자체 문제가 아니라 섹션 경계 문제입니다.

**2. 조사 화면의 가방 라벨 가독성 (chromium-360-investigate).** 번호 배지 01/02/03이 가방마다 위·아래로 다른 위치에 붙고, 03 배지는 밝은 바닥 하이라이트와 겹쳐 대비가 떨어집니다. 배지 위치를 전부 가방 하단 중앙으로 고정하고, 배지에 어두운 반투명 바탕을 깔면 사진이 어떤 톤이어도 읽힙니다. `창가 자리`·`출입문` 핀도 같은 배지 규격으로 통일하면 좋겠습니다.

**3. 피드백 영역의 색 신호 부재 (chromium-360-investigate).** "위치는 맞아요 / 색을 다시 확인해 볼까요?"는 부분 정답인데, 왼쪽 바가 배경과 거의 같은 채도라 맞았는지 틀렸는지 색만으로는 알 수 없습니다. 새 요소 추가 없이, 왼쪽 바와 아이콘 하나만 상태색(부분 정답=앰버, 정답=그린)으로 바꾸면 충분합니다.

세 가지 모두 레이아웃·토큰 수준 수정이며, 새 에셋이나 연출 추가 없이 처리 가능합니다.
