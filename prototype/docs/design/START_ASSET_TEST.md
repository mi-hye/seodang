# 시작 화면 에셋 테스트 — 수정 상태

- 공통 진입점: index.html. 웹과 네이티브 모두 동일 파일. start-asset-test.html은 index로 이동.
- 실제 사용 자산: references/01_start_hanok.png 원본. 새 이미지 생성/편집 없음.
- 잘못 추가했던 단색 가림 박스와 별도 글자를 제거. 화면에 맞춰 원본을 cover 배치하므로 화면 비율에 따라 좌우 일부가 잘림.
- 실제 UI: 원본 버튼 위치에 맞춘 HTML button, 접근성 이름과 클릭 후 눌림 피드백. 다음 화면 없음.
- 미완성: 눈에 보이는 제목과 버튼 글자는 원본 이미지에 합쳐져 있다. 화면상 텍스트를 독립 UI로 구현했다는 완료 기준은 충족하지 못함. 화면 읽기용 h1은 시각적 텍스트 분리를 의미하지 않음.
- 필요한 자산: 제목·버튼·장식 밑줄 없는 동일 배경 분리본.
- 이전 플레이 앱 진입 HTML은 playable.html에 보존. 화면 확장/재디자인 없음.
- 빌드: npm run ios:sync (ios:sync:start-test도 같은 명령 사용).
- 확인: Chromium/WebKit 모바일 탭 동작 확인, 최종 배치 WebKit 360/390/430px 버튼 경계 및 탭 확인.

## 벚꽃 낙화 효과

사용자 요청에 따라 CSS 꽃잎 9개를 원본 위에 추가. 신규 이미지 에셋 없이 이동·좌우 흔들림·회전을 조합. 19–29초 낙하, 5–9px 크기로 절제. pointer-events:none으로 버튼 터치 유지. 동작 줄이기 설정에서는 숨김, 앱 비활성 시 애니메이션 일시정지. WebKit에서 위치 변화/실제 탭/동작 줄이기 확인, iPhone용 서명 빌드 성공.
