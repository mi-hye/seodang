# UI v2 — Claude 협업 개편

2026-10-12 사용자의 “클로드 도움을 받아 UI를 전면 개편” 요청에 따라 기존 worktree에서 실제 UI와 설치형 체험판을 갱신했다. 사건 데이터·진행 엔진·저장 스키마는 유지한다. 원래 인계서의 색감/탭/레이아웃은 이번 사용자 요청으로 다시 설계했으며, 로그인 없음·학습 중심·단일 사건 완결·임시 자산 교체 구조는 유지한다.

## Claude에게 맡긴 범위

이 Mac에 인증된 Claude Code CLI를 사용했다. 첫 요청에서는 UI 소스와 기존 참고 이미지를 읽고 디자인 방향을 제안받았고, 두 번째는 구현 후 실제 브라우저 캡처 4장에 대한 비주얼 리뷰를 받았다. Claude는 읽기 전용 도구로 검토했으며 실제 코드 수정·테스트·iPhone 빌드와 설치는 Codex가 수행했다.

- [Claude의 디자인 제안 원문](CLAUDE_UI_REVIEW.md)
- [구현 화면에 대한 Claude의 최종 리뷰 원문](CLAUDE_VISUAL_QA.md)

두 문서는 외부 모델의 제안/평가이며 사용자의 최종 승인이나 사용자 연구 결과를 뜻하지 않는다.

## 구현

- 노을 한옥·카페 배경을 새로 제작하고, 잉크색 화면·등불빛 버튼·밝은 종이 패널로 시각 체계를 바꿨다.
- 홈은 현재 사건의 큰 이미지와 플레이 버튼이 중심이며 과도한 소개 문구를 줄였다. 메뉴는 이야기·노트·기록 3개다.
- 조사 가방은 밝은 카드에서 분리해 장면 위 SVG 오브젝트로 배치했다. 세 후보를 같은 방식으로 표시하며 선택 후에만 강조한다. 상시 한국어 색·위치 캡션 대신 번호를 쓰고, 한국어 접근성 이름은 유지한다.
- 표현·노트는 큰 일본어와 작은 뜻풀이, 종이 배경으로 구분한다. 대화는 어두운 읽기 패널이다.
- 설정에 일본어 글자 크기 미리보기, 노트·힌트에 바텀시트를 적용했다. 시스템 모션 감소와 수동 정지는 유지한다.
- Claude의 최종 리뷰를 반영해 다음 이야기 섹션 경계, 가방 번호 대비, 부분 정답의 앰버 피드백을 보강했다.
- iOS 상태 표시줄을 밝게 바꾸고 노치·하단 안전영역을 유지했다. 새 버전 설치는 기존 프로토타입의 같은 앱 ID로 갱신했으며 데이터 초기화는 하지 않았다.

의도적으로 적용하지 않은 제안: 자동 타이핑 효과(읽기 속도를 강제하지 않기 위해 전체 표시 유지), 새 폰트 로딩(기기 기본 한·일 폰트 사용), 설정 배율 추가(현재 저장 스키마의 100/120% 유지). 새로운 서당개 외형은 아직 승인되지 않았으므로 동일한 임시 캐릭터를 유지한다.

## 검증과 크기

- 단위 테스트 5개 통과. Chromium·WebKit 360/390/430px의 전체 플레이 포함 브라우저 14개 모두 통과.
- 최종 대비 보완 후 390px 전체 플레이를 두 엔진에서 추가 재확인했다.
- 정상/오답/힌트/노트/글자 120%/모션/진행 복원/탭 충돌/초기화/전이 확인·복습이 연결된다.
- Xcode 27 빌드 성공, 연결된 실물 iPhone 13에 설치·실행 성공. [실기기 캡처](screenshots/iphone-v2.png)에서 새 노트 UI와 밝은 상태 표시줄을 확인했다. 실기기 전체 과정의 자동 테스트를 주장하지 않는다.

동일한 빌드 방식, 파일별 gzip 합산. 모바일과 데스크톱은 같은 엔트리다.

| 범위 | v1 | v2 |
| --- | ---: | ---: |
| 초기 JS와 재귀적 정적 의존성 | 13,446 B | 14,009 B |
| 전체 JS | 15,302 B | 15,920 B |
| 공통 CSS | 5,324 B | 7,931 B |

설정/노트 패널 JS는 계속 동적 import이며 패널 CSS는 공통 CSS에 포함된다. 새 배경 JPEG 합계는 약 1.1 MiB로 JS/CSS 측정에 포함되지 않는다. 현재 화면에서 참조하는 배경만 브라우저가 요청하며 두 이미지는 설치형 앱에 내장한다. 원본 PNG·참고 이미지·Claude 문서는 앱 산출물에 포함하지 않는다.
