# 초기 설정 화면

사용자가 다음 화면으로 선택한 범위: 일본어 학습 도움 수준 선택. 시작 화면 → setup.html → 선택 저장까지 구현. 홈 화면은 이번 배포에 포함하지 않는다.

## 실제 동작
- index.html의 시작하기 버튼이 setup.html로 이동.
- 두 가지 도움 방식은 native radio input으로 선택, HTML submit button으로 저장.
- 기존 storage/engine의 onboard 동작 재사용. 저장된 도움 수준 복원, 사건 진행/표현 기록 유지.
- 저장 불가·호환되지 않는 기록은 오류를 안내하고 기존 데이터를 덮어쓰지 않음.
- 저장 후 같은 화면에 완료 안내. 뒤로 가기는 기존 시작 화면으로 이동.

## 실제 사용 자산 및 누락
- references/01_start_hanok.png를 실제 img로 사용. 상단 배너는 CSS overflow로 원본 하단 330px 영역을 표시. 신규 이미지·캐릭터 생성 없음.
- 화면 제목·설명·선택지·저장 버튼은 모두 실제 HTML UI.
- 초기 설정 전용 분리 이미지/캐릭터 자산 없음. 현재 화면에는 필요 없어 대체 그림 생성하지 않음.
- 도움 방식 문구와 한국어 안내→일본어 학습은 인계서의 임시 기본값. 사용자 확정 범위는 초기 설정 화면 제작.

## 검증
- Chromium/WebKit 각각 모바일 360/390/430px: 시작 연결, 선택, 저장, 새로고침 복원, 사건 기록 보존, 잘못된 저장값 보존, 가로 넘침 없음 확인.
- setup.js 문법 및 웹 빌드, iPhone Debug 서명 빌드 성공.
- 네이티브 실행 진입은 index.html과 동일.

## 번들
데스크톱/모바일은 동일 엔트리. 페이지 이동으로 JS/CSS 모두 분리. 새 의존성 없음.
- 시작 HTML gzip 1966 → 1945 bytes.
- 시작 inline JS gzip 624 → 609 bytes, CSS 1083 → 1083 bytes.
- 설정 화면의 정적 JS 의존성 합계(setup/storage/engine/content): gzip 4246 bytes. 설정 CSS gzip 1181 bytes. 시작 화면에서 불러오지 않음.
- 기존 build.mjs의 initialJS 수치는 보존된 구 플레이 앱용이므로 현재 index 측정치와 구분.

## 반응형 수정

시작 화면의 cover 확대를 제거하고 안전 영역 안에 원본 전체를 맞춤. 최대 너비 480px, 배경 비율 유지, 터치 영역 최소 44px. 원본 비율과 다른 화면에서는 주변에 기존 배경색 여백이 생김.
설정 화면 최대 너비 420px, 유동 제목/가로 여백, 높이 740px 이하에서 배너·여백 축소, 낮은 가로 화면에서 배너 숨김. 내용은 세로 스크롤 가능.
Chromium/WebKit 각각 320×568, 375×667, 390×844, 430×932, 768×1024, 1440×900, 844×390에서 시작 이미지 경계/최대 너비/터치 크기/설정 연결/가로 넘침/선택 저장 확인(14조합). iPhone 서명 빌드 성공.

## Safe area 레이어 분리

- 시작 배경과 벚꽃: 안전 영역 padding 없는 전체 화면 레이어. 모바일 세로에서는 cover, 넓은 화면은 최대 480px 제한. 세로에서 좌우 일부 크롭 가능.
- 시작 버튼: 상단 safe inset+12px, 좌우/하단 safe inset+16px의 별도 interaction 레이어. 원본 이미지에 합쳐진 버튼 좌표를 렌더링 배율에 맞춰 투영. 화면 크기 변경 시 갱신.
- 원본의 제목/버튼 그래픽 자체가 분리된 것은 아님. 새 이미지 생성 없음.
- 설정: 크림색 바탕은 전체 화면, 헤더에만 상단 inset 적용, 스크롤 내용 아래에는 하단 inset+16px.
- 검증: inline JS 문법, 5개 세로 화면의 safe-area 좌표 계산, 네이티브 서명 빌드 성공. 이번 작업에서 로컬 브라우저는 열지 않음.

## 온보딩 3단계 수정 (최신)

1. 일본어 학습/한국어 안내 확인.
2. “난이도를 선택해주세요”: 처음부터 배우기 / 짧은 표현부터 배우기.
3. 선택 내용 확인. 학습 시작을 누를 때 저장 후 기존 사건 플레이로 진입.

작은 안내 문구/처음 설정 라벨 제거. 본문/진행 표시 최소 18px, 선택지/버튼 20px. 전체 흐름은 같은 setup 페이지 안에서 전환하며, 이전 단계에서 선택 유지. 새로운 난이도 콘텐츠를 추가한 것이 아니라 기존 beginner/phrase 도움 설정에 연결한 UI 라벨 변경이다. 기존 사건 코드는 재사용하며 이번에 화면 디자인을 확장하지 않음. 새 이미지 없음.

검증: JS 문법, 기존 Node 테스트 5개, Node VM에서 단계 전환/뒤로/선택 유지/최종 확인 전 미저장/최종 저장/사건 URL 연결 검증. iOS 서명 빌드 성공. 로컬 브라우저 미실행.

## 최신: 언어/난이도 두 단계

- 사용자의 1,2 화면 요청에 맞춰 언어 선택→난이도 선택으로 축소. 헤더 뒤로 버튼은 visibility로 자리 보존, 같은 높이의 제목 영역, 고정 하단 버튼, 선택 영역만 스크롤. 제목 focus preventScroll로 화면 점프 방지.
- 제목 24px, 선택 문구 17px, 버튼 18px. 작은 장식 문구와 배너 제거.
- “배울 언어를 골라볼까요”: 일본어 활성, 한국어 준비 중(비활성). 반대 과정 미제작 상태를 유지.
- 1 글씨를 읽을 줄 몰라요 / 2 글씨는 읽지만 단어가 낯설어요 / 3 짧은 문장을 이해할 수 있어요 / 4 일상 대화를 할 수 있어요 / 5 긴 글을 읽고 의견을 말해요. 2~5 문구 임시안.
- 선택 수준은 onboardingLevel(1~5)에 저장. 기존 데모 도움 모드는 1~2 beginner, 3~5 phrase로 연결. 5단계 교육과정 완성을 의미하지 않음.
- VM으로 5개 수준 각각 저장/뒤로 선택 유지/기존 기록 보존/사건 연결 검증. iOS 서명 빌드 성공. 로컬 브라우저 미실행.
