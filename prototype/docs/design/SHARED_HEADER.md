# 공통 헤더

src/header.js(renderHeader)와 src/header.css를 온보딩 및 메인 플레이 앱에서 공유. 순서: 뒤로가기 / 화면 제목 / 우측 설정 톱니바퀴. 상단 safe area 반영, 버튼 최소 44px. 제목은 20px, 길면 줄바꿈. 별도 브랜드+작은 우측 제목 구조 제거.

적용: 언어 선택, 난이도 선택, 학습 홈, 학습 지도, 배운 표현, 학습 기록, 사건 화면. 지도/복습/기록 본문의 중복 제목 제거. 학습 홈의 뒤로는 온보딩, 하위 화면의 뒤로는 학습 홈, 온보딩 두 번째 단계 뒤로는 첫 번째 단계. 온보딩 첫 단계는 이전 화면이 없어 뒤로 버튼 비활성.

온보딩에서도 공통 설정 패널을 클릭 시 동적 로드. 저장 중 오류/손상된 기록은 보존하고 안내. 페이지 제목/버튼 순서와 메인 중복 제목 제거 검증, Node 테스트 7개, iOS 서명 빌드 성공. 로컬 브라우저 미실행.
