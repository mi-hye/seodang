# 메인 라벨 정리

- 메인/학습 기록의 서당개 안내 이미지 제거. 사건 안 안내 캐릭터는 이번 범위 밖.
- 메인 제목: 일본어 학습. 새 학습/진행 중/완료에 따라 학습 시작하기/학습 이어하기/배운 표현 복습하기.
- 작은 태그, 소요 시간, 장식 부제, 준비 중 사건 목록 제거. 상태 문구는 16px, 버튼/복습 진입 17px, 제목 24~25px.
- 하단 메뉴: 학습 홈 / 배운 표현 / 학습 기록, 15px. 복습/기록 화면의 모호한 주요 제목도 정리.
- 온보딩 완료 후 playable.html#home으로 이동. 기존 사건 흐름과 저장 로직 유지.
- 자산: 기존 카페 배경 재사용. 새 이미지/캐릭터 생성 없음.
- 검증: Node 테스트 5개, 메인 템플릿 새 학습/진행/완료 상태별 동작 라벨 확인, 서당개/작은 라벨 없음 확인, iOS 서명 빌드 성공. 로컬 브라우저 미실행.
- 기존 playable entry gzip: JS 14069→13865 bytes, CSS 7932→8172 bytes. 로딩/온보딩과 분리된 기존 엔트리 유지, 새 의존성 없음.

## 최신: 학습 지도

서당 브랜드 아래 중복 “일본어 학습” 제목 제거. 현재 사건 카드 아래 복습 진입 카드를 학습 지도로 교체. 색과 위치(카페에 남겨진 가방)는 실제 play/review 동작에 연결. 음료 주문/길 묻기는 인계서의 후속 사건 후보이며 disabled 버튼+자물쇠+준비 중으로 표시. 완료해도 미제작 과정은 잠금 유지. 배운 표현 복습은 하단 메뉴로 접근 가능. HTML 목록/버튼과 코드 SVG 연결선 사용, 새 이미지 없음.
검증: 시작 전/학습 중/완료 템플릿에서 활성 동작 1개·잠금 2개·중복 제목 제거 확인, Node 테스트 7개 통과, iOS 서명 빌드 성공. 로컬 브라우저 미실행.

## 최신: 별도 지도 화면 + 가로 줄바꿈

홈의 학습 지도를 별도 stories 뷰로 이동. 홈에는 학습 지도 이동 버튼만 표시. 지도는 CSS Grid auto-fit로 왼쪽부터 가로 배치하고 공간이 부족하면 다음 행으로 내려감. 세로 연결선 제거. 준비 중 과정은 자물쇠와 disabled 유지. 뒤로 버튼은 홈으로 이동. 지도 모듈은 버튼 클릭 시 dynamic import, 작은 지도 CSS는 기존 공통 CSS에 포함. 원래의 학습/복습/잠금 동작 검증, 문법 검사 및 iOS 서명 빌드. 로컬 브라우저 미실행.

## 최신: 지도 형태

사각 카드 그리드 대신 한 장의 지도 위에 숲/등고선/강/다리/길과 학습 지점을 배치. 기존 항목의 가로 순서(첫 줄 2개, 다음 줄 1개)를 유지하고 구불구불한 길로 연결. 지점과 라벨은 HTML 버튼/텍스트, 지형은 코드 SVG. 새 래스터 이미지나 외부 지도 API 없음. 활성 1개/잠금 2개 유지. 지도 모듈은 클릭 후 로드. Node로 지형/지점/잠금/학습·복습 동작 확인, iOS 서명 빌드. 로컬 브라우저 미실행. 초기 플레이 JS gzip 변동 없음, 지도 모듈 포함 총 JS gzip +917 bytes, 공통 CSS gzip +255 bytes.

## 최신: 지도 배경 제거

사용자 피드백에 따라 지형 SVG(숲/강/다리/등고선/건물)와 밝은 배경을 제거. 기존 어두운 화면 위에 연결선·학습 지점·잠금만 유지. 화면 이동과 학습 가능 상태는 동일. 문법 검사 및 iOS 빌드 성공. 로컬 브라우저 미실행.
