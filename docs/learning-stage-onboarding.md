# 5단계 학습 온보딩 (2026-10-02)

신규 사용자는 서당개 소개 → 단계 선택 → 오늘의 수업으로 이동한다.
기존 저장 데이터가 있는 사용자는 소개를 생략하고 단계만 한 번 선택한다.
설정 화면 맨 위의 ‘난이도 설정’에서 다시 선택할 수 있다. 다른 단계를 선택하면
오늘의 수업만 새로 구성되며 쓰기 기록, 퀴즈 기록, 간식과 보상 한도는 유지된다.

## 현재 온보딩 UI (2026-10-06)

1. 서당개 만나기: 홈과 같은 픽셀 방, 움직이는 서당개, `학습 → 간식 → 성장` 아이콘.
   쓰다듬으면 미리보기 표정만 바뀌며 먹이나 성장 데이터는 변경하지 않는다.
2. 난이도 선택: 기존 다섯 선택지와 `오늘의 수업 시작`. 선택 전 버튼은 비활성화한다.
3. 완료하면 선택 난이도의 오늘의 수업으로 바로 진입한다. 홈으로 우회하지 않는다.

긴 소개 문구와 카드별 서브라벨은 없다. 두 칸 진행 표시와 소개로 돌아가기만 제공한다.
난이도를 선택한 뒤 소개로 돌아가도 같은 화면 세션에서는 선택이 유지된다.
소개 다음으로 진행한 기록이 있으면 재시작 시 난이도 선택부터 이어간다.
시작 버튼은 하단에 고정하고 본문만 스크롤한다. 동작 줄이기 설정과 화면 비활성화 시
강아지 움직임을 멈춘다. 기존 사용자에게 온보딩을 다시 강제하거나 기록을 초기화하지 않는다.

설정 모드는 소개·진행 표시 없이 난이도 선택으로 바로 들어가며, 저장·취소 후 설정으로 돌아간다.
개발 환경의 `설정 → 온보딩 다시 보기`로 처음부터 확인할 수 있다.

### 재구성 검증

- 타입 검사·177개 테스트·웹/Android/iOS production export 통과.
- 웹 390×844 소개/선택 화면, 320×568 마지막 선택지 스크롤과 고정 버튼 확인.
- 선택 전 비활성화, 소개 왕복 시 선택 유지, 온보딩 완료 후 실제 1단계 수업 표시 확인.
- 설정 모드에서 소개를 건너뛰고 현재 선택·저장·취소가 표시되는 것을 확인했다.
- 재진입 조건은 신규 사용자, 소개 완료 사용자, 기존 단계 사용자, 설정 진입을 단위 테스트한다.
- 실기기 앱 데이터는 초기화하지 않았으며 이번 UI의 실기기 조작은 미검증이다.

기존 lazy route와 공통 픽셀 렌더러를 재사용한다. 새 의존성·전역 CSS는 없다.
동일 production 웹 설정의 데스크톱·모바일 공통 초기 JS gzip은
834,993 → 835,142 B (+149 B), 전체 JS는 925,129 → 926,153 B (+1,024 B).
온보딩 비동기 청크는 1,310 → 2,185 B다. 외부 CSS 0 B, 인라인 reset CSS 192 B는 동일하다.
초기 증가는 번역과 공통 진입 판별 코드이며, 실제 온보딩 UI는 비동기 청크에 유지된다.

## 난이도 설정으로 이동 (2026-10-06)

- 학습 탭의 단계 변경 행을 제거하고, 설정 맨 위에 `난이도 설정`을 배치했다.
- 기존 `/learning-start` lazy 화면을 `from=settings` 모드로 재사용한다.
- 설정 진입 시 현재 난이도를 미리 선택하고, 부연 문구 없이 `저장`·`취소`를 제공한다.
- 저장은 기존 선택 로직을 적용한 뒤 설정으로 복귀한다. 취소는 변경 없이 설정으로 복귀한다.
- 신규 온보딩의 소개 → 질문 → 오늘의 수업 흐름은 유지한다.
- 타입 검사·174개 테스트·웹 production export 통과. 웹 390×844에서 설정 진입,
  다른 선택 후 취소 시 기존 값 유지, 같은 난이도 저장 후 설정 복귀를 확인했다.
- 웹 초기 JS(데스크톱·모바일 공통) gzip 834,909 → 834,993 B (+84 B),
  전체 JS 925,046 → 925,129 B (+83 B). 선택 화면 청크 1,260 → 1,310 B.
  외부 CSS 0 B·인라인 reset CSS 192 B는 동일하다. 기존 lazy 경계와 의존성을 유지한다.
  이번 이동 후 네이티브 재빌드는 하지 않았다.

| 선택 단계 | 오늘의 수업 |
| --- | --- |
| 1 · 문자 입문 | 히라가나 쓰기 3개 · 처음에는 あ → い → う |
| 2 · 기초 단어 | 사물·행동을 나타내는 단어 3개, 글자 쓰기 없음 |
| 3 · 생활 문장 | 조사·빈칸·낱말 순서 3개 |
| 4 · 중급 독해 | 여러 문장의 조건·예외·이유를 연결하는 4지선다 3개 |
| 5 · 고급 문맥·뉘앙스 | 필자의 논리·완곡한 거절·부분 부정 등 4지선다 3개 |

로컬 문제 풀은 가나 92개, 단어 8개, 문장 6개, 중급 6개, 고급 6개다.
중·고급 문제는 기존 쉬운 대화와 다른 ID를 사용한다. 기존에 저장된 수업은
문제를 포함한 원래 진도를 유지하며, 이후 새 수업부터 변경된 문제 풀이 적용된다.
단, 아직 끝내지 않은 입문 단계의 옛 가나 찾기 수업은 아래 쓰기 수업으로 전환한다.
기존 단계 ID는 유지하고 `advanced`를 추가했다. JLPT 급수 인증이나 배치고사는 아니다.
자동 레벨 진단이나 전체 교육과정은 아니다. 듣기·말하기 기능은 추가하지 않았다.
퀴즈는 정답 후 ‘다음으로’를 눌렀을 때 저장된다. 퀴즈 기록은 쓰기 기록과 분리한다.
간식은 자유학습과 합산하여 하루 3개까지이며 같은 학습 대상의 중복 지급을 방지한다.

## 번들 점검

온보딩과 수업은 초기 화면의 필수 UI가 아니므로 각각 lazy route로 분리했다.
문제 데이터도 수업 화면의 비동기 청크 안에 둔다. 신규 의존성은 없다.
동일 조건의 production export 전후 gzip 바이트 비교:

| 대상 | 이전 | 이후 | 증감 |
| --- | ---: | ---: | ---: |
| 초기 웹 JS (데스크톱·모바일 공통) | 831,020 | 831,160 | +140 |
| 전체 웹 JS (비동기 청크 포함) | 915,797 | 920,406 | +4,609 |
| 초기·전체 외부 CSS (공통) | 0 | 0 | 0 |
| Android Hermes 전체 번들 | 2,573,721 | 2,575,899 | +2,178 |
| iOS Hermes 전체 번들 | 2,571,739 | 2,574,662 | +2,923 |

React Native Web 스타일은 JS에 포함된다. 웹은 단일 초기 entry와 비동기 청크로
출력되며 별도 정적 JS 의존 청크가 없다. 비동기 청크는 온보딩 1,285바이트,
수업 10,719바이트다. 네이티브는 단일 Hermes 번들로 출력되므로 웹의 다운로드
분리 효과가 네이티브 번들 크기 감소를 의미하지 않는다.
