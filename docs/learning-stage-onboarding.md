# 5단계 학습 온보딩 (2026-10-02)

신규 사용자는 서당개 소개 → 단계 선택 → 오늘의 수업으로 이동한다.
기존 저장 데이터가 있는 사용자는 소개를 생략하고 단계만 한 번 선택한다.
학습 탭의 ‘단계 바꾸기’에서 다시 선택할 수 있다. 다른 단계를 선택하면
오늘의 수업만 새로 구성되며 쓰기 기록, 퀴즈 기록, 간식과 보상 한도는 유지된다.

| 선택 단계 | 오늘의 수업 |
| --- | --- |
| 1 · 문자 입문 | 가나 찾기 3개 + 짧은 쓰기 1개 |
| 2 · 기초 단어 | 사물·행동을 나타내는 단어 3개, 글자 쓰기 없음 |
| 3 · 생활 문장 | 조사·빈칸·낱말 순서 3개 |
| 4 · 중급 독해 | 여러 문장의 조건·예외·이유를 연결하는 4지선다 3개 |
| 5 · 고급 문맥·뉘앙스 | 필자의 논리·완곡한 거절·부분 부정 등 4지선다 3개 |

로컬 문제 풀은 가나 92개, 단어 8개, 문장 6개, 중급 6개, 고급 6개다.
중·고급 문제는 기존 쉬운 대화와 다른 ID를 사용한다. 기존에 저장된 수업은
문제를 포함한 원래 진도를 유지하며, 이후 새 수업부터 변경된 문제 풀이 적용된다.
기존 단계 ID는 유지하고 `advanced`를 추가했다. JLPT 급수 인증이나 배치고사는 아니다.
자동 레벨 진단이나 전체 교육과정은 아니다. 듣기·말하기 기능은 추가하지 않았다.
퀴즈는 정답 후 ‘다음으로’를 눌렀을 때 저장된다. 퀴즈 기록은 쓰기 기록과 분리한다.
간식은 자유학습과 합산하여 하루 3개까지이며 같은 학습 대상의 중복 지급을 방지한다.

## 검증

- `npm run quality:check:local`: 타입 검사 및 테스트 160개 통과.
- 웹·Android·iOS 프로덕션 export 성공, `git diff --check` 통과.
- 웹 360×740: 5단계 카드, 고급 직접 진입, 긴 지문·보기 줄바꿈,
  오답 해설, 정답 저장, 새로고침 후 고급 진도 복원 확인.
- 자동 테스트: 5단계의 서로 다른 문제 풀, 중·고급 4지선다,
  고급 완료·다음 날 문제 순환·보상 한도, 기존 4단계 저장 수업 호환 확인.
- 연결된 Galaxy Note8: 최신 개발 번들로 재시작, 5개 단계가 표시된 화면 확인.
  실제 기기의 기존 4단계 선택·학습 기록·간식은 변경하지 않았다.
- 확인한 웹 콘솔 및 Android 앱 로그에 런타임 오류 없음.

## 번들 점검

온보딩과 수업은 초기 화면의 필수 UI가 아니므로 각각 lazy route로 분리했다.
문제 데이터도 수업 화면의 비동기 청크 안에 둔다. 신규 의존성은 없다.
동일 조건의 production export 전후 gzip 바이트 비교:

| 대상 | 이전 | 이후 | 증감 |
| --- | ---: | ---: | ---: |
| 초기 웹 JS (데스크톱·모바일 공통) | 831,020 | 831,160 | +140 |
| 전체 웹 JS (비동기 청크 포함) | 915,797 | 920,406 | +4,609 |
| 초기·전체 외부 CSS (공통) | 0 | 0 | 0 |
| Android Hermes 전체 번들 | 2,573,721 | 2,575,899 | +2,178 |
| iOS Hermes 전체 번들 | 2,571,739 | 2,574,662 | +2,923 |

React Native Web 스타일은 JS에 포함된다. 웹은 단일 초기 entry와 비동기 청크로
출력되며 별도 정적 JS 의존 청크가 없다. 비동기 청크는 온보딩 1,285바이트,
수업 10,719바이트다. 네이티브는 단일 Hermes 번들로 출력되므로 웹의 다운로드
분리 효과가 네이티브 번들 크기 감소를 의미하지 않는다.
