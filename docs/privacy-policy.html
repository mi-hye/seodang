Seodang Privacy Policy

Last updated: June 8, 2026

Service

Seodang is a kanji learning app. The app lets users browse kanji categories, view kanji details, practice writing, save favorites, track recent practice, and configure study reminders.

Data Stored On Your Device

Seodang stores the following data locally on the user's device:

  • App language and theme settings
  • First-run onboarding progress
  • Favorite kanji
  • Practice progress, scores, attempts, and recent practice history
  • Category progress reset state
  • Study reminder settings

This local data is stored with AsyncStorage and is used only to provide app features. It is not sold.

Data Fetched From Supabase

Seodang fetches public kanji learning data from Supabase, including kanji metadata, categories, stroke order data, and example sentences when available. Seodang does not currently require user login and does not upload individual user practice history to Supabase.

Notifications

If the user enables study reminders, Seodang asks for notification permission and schedules local notifications on the device. Notification settings are stored locally. The app does not send reminder messages to a remote server.

Data Sharing

Seodang does not sell user data. The app uses Supabase as a backend content provider. Network requests to Supabase may include standard technical information processed by Supabase as part of providing the service.

Third-Party Services

  • Supabase, for public kanji data and Edge Functions
  • Expo / React Native, for app runtime, builds, and notifications

User Choices

Users can change app settings, remove favorites, reset category progress, edit or delete study reminders, disable notifications in device settings, or delete local app data by uninstalling the app.
