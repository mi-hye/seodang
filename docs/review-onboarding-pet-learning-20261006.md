# 온보딩·서당개·오늘의 수업 머지 전 리뷰

## 범위

- 서당개 Lv.10–40 외형과 레벨별 성장 안내 모달, 홈 보조 문구 정리.
- 소개 → 난이도 → 오늘의 수업 온보딩, 설정 내 난이도 변경.
- 입문 히라가나 쓰기, 미완료 레거시 수업 전환, 진행률 옆 전구 힌트.
- 마케팅 작업물과 개인 노트는 제외한다.
- 서버의 일별 수업 생성은 미구현이며 이번 변경에 포함하지 않는다.

## 발견 및 수정

하단 중단 버튼 제거 후 온보딩에서 `replace`로 진입한 수업에는 이전 화면이 없어
완료 전 나갈 수 없었다. 수업 헤더에 뒤로가기를 제공하고, 이전 화면이 없는 경우
`/learn`으로 이동하도록 수정했다. 하단의 삭제된 안내 문구는 복원하지 않았다.
웹에서 직접 진입 → 뒤로가기 → 학습 → 수업 재진입 시 같은 문제와 1/3 진도가
보존되는 것을 확인했다. 코드 리뷰에서 추가 머지 차단 문제는 발견하지 못했다.

## 검증

- `npm run quality:check`: 타입 검사, 180개 단위 테스트 통과.
- DB 품질 검사: 실용 한자 2,382개 대상 문제 0건.
- 카테고리 일관성 smoke 검사: 2개 언어, 9개 표본 카테고리, 386개 글자, 문제 0건.
- `expo export --platform all`: 웹·Android·iOS 성공.
- `git diff --check`: 통과.
- 이전 UI 검증: 입문 쓰기 자동 진입, 힌트 열기·정답 후 숨김·다음 문제 초기화,
  성장 안내 모달과 난이도 설정. 실제 iPhone에서 입문 あ 쓰기 진입을 확인했다.
- 이번 헤더 수정의 검증은 웹에서 수행했다. 전체 학습의 실기기 손글씨 채점과
  모든 화면의 접근성·기기별 조합을 자동화한 E2E 검증은 아니다.

## 번들 검증

기준은 `main` 3501188의 별도 소스 스냅샷과 최종 변경본이다. 동일 의존성·환경의
`expo export --platform all` 출력 gzip 크기를 비교했다. 수업·온보딩·성장 안내는
기존 lazy 경계를 유지하며, 새 클라이언트 의존성이나 전역 CSS를 추가하지 않았다.

| 대상 | main | 변경 후 |
| --- | ---: | ---: |
| 초기 웹 JS (데스크톱·모바일 공통) | 832,874 B | 835,376 B |
| 전체 웹 JS | 922,176 B | 927,094 B |
| 초기·전체 외부 CSS | 0 B | 0 B |
| Android 단일 Hermes 번들 | 2,579,820 B | 2,591,675 B |
| iOS 단일 Hermes 번들 | 2,578,339 B | 2,590,512 B |

웹은 HTML에서 로드하는 단일 초기 entry와 선택적 비동기 청크로 구성된다.
HTML 인라인 스타일 원문은 양쪽 모두 379 B다. 초기 JS 증가는 공통 픽셀 렌더러의
외형 디테일·번역·라우트 코드이며, 새 성장 안내 화면 본문은 초기 청크 밖에 있다.
네이티브는 단일 번들이므로 웹의 다운로드 분리가 네이티브 전체 크기 감소를 뜻하지 않는다.
