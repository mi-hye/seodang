# 서당개 픽셀 성장과 개발 미리보기

## 성장 규칙

| 레벨 | 외형 단계 | 실제 도트 격자 |
| --- | --- | --- |
| 1–9 | 1 | 24×24 |
| 10–19 | 2 | 32×32 |
| 20–29 | 3 | 48×48 |
| 30–39 | 4 | 64×64 |
| 40 이상 | 5 | 96×96 |

먹이 3개당 1레벨, 숫자 레벨 상한 없음은 유지한다. 기존 저장 데이터의
`totalFed`, 간식, 보상 기록을 수정하거나 초기화하지 않는다.
기존 리본·모자 추가 방식은 픽셀 밀도와 디테일 성장으로 대체한다.

1단계는 기존 도트 원본을 유지한다. 이후 단계는 더 촘촘한 정수 픽셀 격자에
윤곽을 그리며 눈 하이라이트, 털 음영, 볼·발 디테일을 추가한다.
낮은 해상도 이미지를 단순 확대하는 방식이 아니다. 외부 이미지나 의존성은 없다.
SVG는 색상별 경로로 묶어 노드 수를 제한하고, 외형·표정별로 캐시한다.
기존 홈 이동·숨쉬기와 별도 꼬리 애니메이션은 유지한다.

## 개발 도구

개발 빌드의 홈 상단 플라스크 버튼 → `DEV · 서당개 외형`.

- Lv.1/10/20/30/40 바로 보기, ±1레벨로 경계 확인.
- 기쁜 표정, 꼬리 움직임 켜기/끄기. OS 동작 줄이기 설정 존중.
- 같은 표시 크기로 5단계 비교, 실제 레벨로 돌아가기.
- 변경은 모달 내부 상태에만 적용. 실제 레벨·먹이·학습 기록을 변경하지 않는다.
- 닫으면 초기화한다. 영구 디버그 설정이나 개발용 딥링크는 없다.

`__DEV__` 조건 안의 lazy import로 클릭할 때만 로드한다. 출시 빌드에서는
버튼뿐 아니라 도구 모듈도 제거된다. 외형 렌더러는 실제 홈에 필요하므로 공통 번들에 둔다.

## 검증 (2026-10-02)

- 타입 검사, 단위 테스트 164개, 웹·Android·iOS production export 통과.
- 9/10, 19/20, 29/30, 39/40 경계와 999레벨까지 자동 테스트.
- 5개 격자의 유효 좌표·서로 다른 경로·밀도 증가·캐시·표정·꼬리 분리 검증.
- 개발 웹: 모달 열기/닫기, 9→10 경계, 40레벨, 표정·움직임 토글,
  실제 레벨 복귀, 닫은 후 기존 Lv.1·간식 2개 보존 확인. 콘솔 오류 없음.
- Galaxy Note8: 앱 재시작 후 홈 플라스크 버튼과 네이티브 미리보기 표시 확인.
  실제 Lv.1·간식 3개 유지, 재시작한 앱 로그에 런타임 오류 없음.
- 프로덕션 JS/Hermes 10개 파일에서 개발 모듈 이름과 전용 UI 문구가
  UTF-8/UTF-16LE 모두 없는 것을 확인. 별도 개발 청크도 없음.
