# 서당개 픽셀 성장과 개발 미리보기

## 성장 규칙

| 레벨 | 외형 단계 | 실제 도트 격자 |
| --- | --- | --- |
| 1–9 | 1 | 24×24 |
| 10–19 | 2 | 32×32 |
| 20–29 | 3 | 48×48 |
| 30–39 | 4 | 64×64 |
| 40 이상 | 5 | 96×96 |

먹이 3개당 1레벨, 숫자 레벨 상한 없음은 유지한다. 기존 저장 데이터의
`totalFed`, 간식, 보상 기록을 수정하거나 초기화하지 않는다.
픽셀 밀도와 디테일이 성장하며, Lv.20에는 빨간 스카프, Lv.30에는 두루마리,
Lv.40에는 선비 모자와 작은 옥색 스카프가 더해진다. 도포는 사용하지 않는다.

1단계는 기존 도트 원본을 유지한다. 이후 단계는 더 촘촘한 정수 픽셀 격자에
윤곽을 그리며 눈 하이라이트, 털 음영, 볼·발 디테일을 추가한다.
낮은 해상도 이미지를 단순 확대하는 방식이 아니다. 외부 이미지나 의존성은 없다.
SVG는 색상별 경로로 묶어 노드 수를 제한하고, 외형·표정별로 캐시한다.
기존 홈 이동·숨쉬기와 별도 꼬리 애니메이션은 유지한다.

## 사용자 성장 안내

홈 `서당개` 라벨 바로 오른쪽 `?` → 성장 안내 모달(`/pet-growth`).

- 실제 렌더러로 Lv.1·10·20·30·40 모습을 모두 공개한다.
- 화면에는 레벨과 강아지 그림만 표시하고, 현재 모습은 테두리와 배경으로 구분한다.
- 설명·단계 이름·상태 부연 문구는 표시하지 않는다. 스크린리더용 설명은 유지한다.
- 홈의 속담·쓰다듬기 안내·간식 설명 문구도 제거한다. 성장 수치·보상 표시와 반응 말풍선은 유지한다.
- 안내 카드는 미리보기 전용이다. 성장·먹이·학습 기록을 변경하지 않는다.
- 한국어·일본어, 테마 색상, 세로 스크롤, 닫기 및 Android 뒤로 가기를 지원한다.

`PetGrowthGuide`는 lazy import로 분리한다. 웹에서는 홈 진입 시 갤러리 코드를
읽지 않고, 공통 렌더러만 재사용한다. 네이티브 production export는 단일 Hermes
번들이므로 전송 크기 자체가 지연 로드되는 것은 아니다.

### 성장 안내 검증 (2026-10-06)

- 타입 검사와 단위 테스트 174개 통과. 다음 외형 레벨 경계 및 40 이상 처리 검증.
- 웹 320×640·390×844: 카드 배치, 마지막 단계까지 스크롤, 홈 `?` 열기/닫기,
  Lv.1·간식 1개 유지 확인. 실기기에서의 이번 안내 화면 조작은 미검증.
- 한국어·일본어 번역 키 및 치환 변수 일치 확인.
- 동일 설정 `expo export --platform all` 전후 비교. 웹은 데스크톱·모바일 공통
  HTML entry 1개이며 정적 ESM 의존 청크 없음. 갤러리 비동기 청크 gzip 1,189 B.

| gzip 바이트 | 이전 | 이후 | 변화 |
| --- | ---: | ---: | ---: |
| 초기 웹 JS (데스크톱·모바일 공통) | 833,648 | 834,801 | +1,153 |
| 전체 웹 JS | 922,927 | 925,286 | +2,359 |
| 초기·전체 외부 CSS | 0 | 0 | 0 |
| HTML 인라인 reset CSS | 192 | 192 | 0 |
| iOS 전체 Hermes | 2,581,151 | 2,585,259 | +4,108 |
| Android 전체 Hermes | 2,584,787 | 2,587,691 | +2,904 |

초기 증가분은 진입 버튼·라우트·번역 및 공통 성장 조회 코드다.
화면 스타일은 JS 안에 들어 있어 갤러리 청크와 함께 분리된다.

### 부연 문구 정리 검증 (2026-10-06)

상단 `?` 진입 및 레벨·그림만 있는 갤러리를 390×844 웹 화면에서 확인했다.
타입 검사·174개 테스트·웹 production export 통과. lazy 경계는 변경하지 않았다.
동일 production 웹 설정의 데스크톱·모바일 공통 초기 JS gzip은
834,801 → 834,727 B, 전체 JS는 925,286 → 924,864 B로 감소했다.
갤러리 청크는 1,189 → 841 B, 외부 CSS는 0 B, 인라인 reset CSS는 192 B로 유지된다.
이번 문구 정리 후 네이티브 export는 다시 실행하지 않았다.

### 도움말 위치·닫기 정렬 (2026-10-06)

`?`를 서당개 라벨과 같은 행으로 묶고, 간식 배지는 오른쪽에 유지한다.
성장 시트는 기본 네이티브 헤더 대신 제목·44×44 닫기 버튼을 같은 행에 배치한다.
시트 자체의 SafeAreaProvider로 상단 여백을 계산해 부모 화면의 여백이 중복되지 않게 한다.
아이폰 13 개발 빌드 화면에서 제목과 X의 정렬을 확인했다. 웹에서는 라벨 옆 버튼과 닫기를 확인했다.
타입 검사·174개 테스트·웹 production export 통과. 지연 로딩 경계는 그대로다.
초기 웹 JS gzip(데스크톱·모바일 공통)은 834,727 → 834,909 B, 전체 JS는
924,864 → 925,046 B(+182 B). 갤러리 청크 841 B, 외부 CSS 0 B,
인라인 reset CSS 192 B로 유지된다. 이번 정렬 수정은 실행 중 개발 앱에 반영했으며 네이티브 재빌드는 하지 않았다.

## 개발 도구

개발 빌드의 홈 상단 플라스크 버튼 → `DEV · 서당개 외형`.

- Lv.1/10/20/30/40 바로 보기, ±1레벨로 경계 확인.
- 기쁜 표정, 꼬리 움직임 켜기/끄기. OS 동작 줄이기 설정 존중.
- 같은 표시 크기로 5단계 비교, 실제 레벨로 돌아가기.
- 변경은 모달 내부 상태에만 적용. 실제 레벨·먹이·학습 기록을 변경하지 않는다.
- 닫으면 초기화한다. 영구 디버그 설정이나 개발용 딥링크는 없다.

`__DEV__` 조건 안의 lazy import로 클릭할 때만 로드한다. 출시 빌드에서는
버튼뿐 아니라 도구 모듈도 제거된다. 외형 렌더러는 실제 홈에 필요하므로 공통 번들에 둔다.

## 검증 (2026-10-02)

- 타입 검사, 단위 테스트 164개, 웹·Android·iOS production export 통과.
- 9/10, 19/20, 29/30, 39/40 경계와 999레벨까지 자동 테스트.
- 5개 격자의 유효 좌표·서로 다른 경로·밀도 증가·캐시·표정·꼬리 분리 검증.
- 개발 웹: 모달 열기/닫기, 9→10 경계, 40레벨, 표정·움직임 토글,
  실제 레벨 복귀, 닫은 후 기존 Lv.1·간식 2개 보존 확인. 콘솔 오류 없음.
- Galaxy Note8: 앱 재시작 후 홈 플라스크 버튼과 네이티브 미리보기 표시 확인.
  실제 Lv.1·간식 3개 유지, 재시작한 앱 로그에 런타임 오류 없음.
- 프로덕션 JS/Hermes 10개 파일에서 개발 모듈 이름과 전용 UI 문구가
  UTF-8/UTF-16LE 모두 없는 것을 확인. 별도 개발 청크도 없음.

외형 계산과 색상 데이터가 초기 증가분의 주요 원인이다. 웹은 단일 정적 entry와
비동기 화면 청크 구조이고, 스타일은 JS에 포함된다. 네이티브는 단일 Hermes 번들이다.
