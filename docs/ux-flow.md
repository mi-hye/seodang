# 화면별 사용자 플로우 및 와이어프레임 초안

## 1. 문서 목적

이 문서는 MVP 설계 문서를 기준으로 실제 앱 화면 흐름을 구체화하기 위한 초안이다.
목표는 다음 두 가지다.

- 사용자가 어떤 순서로 앱을 쓰는지 명확히 한다.
- 각 화면에서 무엇을 보여주고 어떤 액션을 받아야 하는지 정리한다.

초기에는 두 사용자군을 모두 지원하되, 화면 구조는 최대한 공통으로 유지한다.

## 2. 핵심 사용자 플로우

### 플로우 A: 한국인 일본어 학습자

1. 홈 진입
2. 학습 분류 선택
3. 한자 목록 탐색 또는 검색
4. 한자 상세 확인
5. 획순 확인
6. 쓰기 연습 진행
7. 결과 확인
8. 복습 목록에 저장 또는 다음 한자 진행

### 플로우 B: 일본 초중등 학생

1. 홈 진입
2. 학년별 한자 세트 선택
3. 오늘의 학습 시작
4. 쓰기 연습 진행
5. 결과 확인
6. 오답 재도전
7. 진도 완료 확인

## 3. 공통 앱 구조

초기 MVP는 아래 5개 주요 화면을 기준으로 설계한다.

- 홈
- 한자 목록
- 한자 상세
- 쓰기 연습
- 결과 / 복습

설정 화면은 MVP에서 별도 최상위 화면으로 분리하지 않고 홈 또는 프로필 진입에서 간단히 제공해도 된다.

## 4. 네비게이션 구조

```text
Home
 ├─ CharacterList
 │   └─ CharacterDetail
 │       └─ PracticeSession
 │           └─ PracticeResult
 └─ ReviewList
     └─ PracticeSession
         └─ PracticeResult
```

## 5. 화면별 상세 설계

### 5.1 홈 화면

목적:

- 사용자가 지금 무엇을 해야 하는지 빠르게 알게 한다.
- 학습 시작, 복습 시작, 사용자 그룹별 진입점을 제공한다.

주요 UI:

- 앱 타이틀
- 오늘의 학습 시작 버튼
- 복습 필요 개수 카드
- 사용자 그룹 선택 카드
  - 한국인 학습자
  - 일본 초중등 학습자
- 최근 학습 이어하기
- 추천 학습 세트

주요 액션:

- 오늘의 학습 시작
- 학습 경로 선택
- 복습 바로가기
- 최근 학습 이어하기

와이어프레임:

```text
+--------------------------------------------------+
| 로고 / 앱 이름                                   |
| "오늘도 한자 한 글자씩"                          |
|                                                  |
| [ 오늘의 학습 시작 ]                              |
|                                                  |
| [ 복습 필요 12자 ] [ 최근 학습 이어하기 ]         |
|                                                  |
| 대상 선택                                         |
| [ 한국인 학습자 ] [ 일본 초중등 ]                 |
|                                                  |
| 추천 세트                                         |
| - JLPT N5 기본 한자                               |
| - 초등 1학년 한자                                 |
+--------------------------------------------------+
```

상태:

- 오늘의 추천 세트
- 복습 개수
- 최근 학습 정보
- 선택된 사용자 타입

### 5.2 한자 목록 화면

목적:

- 학습 가능한 한자를 탐색한다.
- 필터, 검색, 진도 상태를 통해 원하는 학습 단위를 찾는다.

주요 UI:

- 상단 검색창
- 필터 탭
  - 학년별
  - JLPT별
  - 테마별
- 한자 카드 리스트
- 학습 상태 배지
  - 미학습
  - 학습 중
  - 복습 필요
  - 완료

주요 액션:

- 검색
- 필터 변경
- 카드 선택

와이어프레임:

```text
+--------------------------------------------------+
| < 뒤로   한자 목록                                |
| [ 검색: 한자 / 뜻 / 읽기 ]                        |
|                                                  |
| [ 학년별 ] [ JLPT ] [ 테마 ]                      |
|                                                  |
| [日] 해, 날      학습 중                          |
| [学] 배우다      미학습                            |
| [校] 학교        복습 필요                        |
| [先] 먼저        완료                              |
+--------------------------------------------------+
```

상태:

- 현재 필터
- 검색어
- 정렬 기준
- 목록 데이터
- 진도 상태 맵

### 5.3 한자 상세 화면

목적:

- 쓰기 전 필요한 정보를 빠르게 보여준다.
- 한자에 대한 이해와 연습 진입을 동시에 지원한다.

주요 UI:

- 큰 한자 표시
- 뜻
- 음독 / 훈독
- 예문
- 획수 / 학년 / JLPT 정보
- 획순 보기 버튼
- 쓰기 연습 시작 버튼

주요 액션:

- 획순 애니메이션 재생
- 쓰기 연습 시작
- 즐겨찾기

와이어프레임:

```text
+--------------------------------------------------+
| < 뒤로   한자 상세                                |
|                                                  |
|                  学                               |
|                배우다                             |
|                                                  |
| 음독: ガク                                        |
| 훈독: まなぶ                                      |
| 획수: 8 / JLPT: N5 / 학년: 1                      |
|                                                  |
| 예문                                               |
| 学校  がっこう  학교                               |
| 学ぶ  まなぶ    배우다                             |
|                                                  |
| [ 획순 보기 ]   [ 쓰기 연습 시작 ]                 |
+--------------------------------------------------+
```

상태:

- 선택 한자 데이터
- 획순 애니메이션 표시 여부
- 예문 접힘/펼침

### 5.4 쓰기 연습 화면

목적:

- 사용자가 직접 한자를 써 보게 한다.
- 쓰기 흐름에만 집중하게 한다.

주요 UI:

- 현재 연습 한자
- 흐리게 표시된 가이드 또는 빈 칸
- 획순 참고 버튼
- 입력 캔버스
- 현재 획 표시
- 다시 쓰기
- 제출

주요 액션:

- stroke 입력
- 다시 쓰기
- 힌트 보기
- 제출

와이어프레임:

```text
+--------------------------------------------------+
| < 뒤로   쓰기 연습                                |
|                                                  |
| 목표 한자: 学                                      |
| 현재 획: 3 / 8                                    |
| [ 획순 힌트 ] [ 다시 쓰기 ]                        |
|                                                  |
| +----------------------------------------------+ |
| |                                              | |
| |                 입력 캔버스                  | |
| |                                              | |
| +----------------------------------------------+ |
|                                                  |
| [ 제출 ]                                         |
+--------------------------------------------------+
```

상태:

- 현재 세션
- 입력된 stroke 목록
- 현재 stroke index
- 힌트 사용 여부
- 제한 시간 여부

### 5.5 결과 / 복습 화면

목적:

- 현재 시도의 결과를 보여준다.
- 다음 행동을 분명히 제시한다.

주요 UI:

- 성공/실패 상태
- 점수 또는 정확도
- 간단한 피드백 문장
- 틀린 포인트 안내
- 다시 연습
- 다음 한자
- 복습 목록 추가

주요 액션:

- 재도전
- 다음 문제
- 복습 저장

와이어프레임:

```text
+--------------------------------------------------+
| 결과                                              |
|                                                  |
| 성공!                                             |
| 정확도 82점                                       |
|                                                  |
| 피드백                                             |
| - 4번째 획 시작점이 조금 어긋났어요               |
| - 전체 순서는 잘 맞았어요                         |
|                                                  |
| [ 다시 연습 ] [ 다음 한자 ]                        |
| [ 복습에 추가 ]                                    |
+--------------------------------------------------+
```

상태:

- 판정 결과
- 점수
- 피드백 메시지
- 복습 반영 여부

## 6. 복습 흐름

별도 화면으로 확장할 수 있지만 MVP에서는 홈의 카드에서 진입해도 충분하다.

복습 흐름:

1. 홈에서 복습 필요 카드 선택
2. 복습 목록 진입
3. 우선순위 높은 한자부터 연습
4. 결과에 따라 복습 우선순위 갱신

복습 목록 최소 UI:

- 한자
- 마지막 학습 날짜
- 오답 횟수
- 추천 복습 우선순위

## 7. 사용자 타입 분기 방식

초기에는 앱을 두 개로 나누지 말고 설정값으로 분기한다.

### 한국인 학습자 모드

- 한국어 뜻 강조
- JLPT 및 어휘 기반 진입
- 읽기 정보 비중 확대

### 일본 초중등 모드

- 학년별 진입 강조
- 복습/반복 훈련 버튼 강조
- 더 단순한 언어와 UI 제공

## 8. UX 원칙

### 원칙 1: 한 화면에 한 가지 목표만 둔다

- 상세 화면은 이해
- 연습 화면은 쓰기
- 결과 화면은 피드백

### 원칙 2: 텍스트보다 행동 버튼을 먼저 보이게 한다

- 초중등 사용자도 바로 이해할 수 있어야 한다.

### 원칙 3: 틀렸다는 말보다 무엇이 틀렸는지 보여준다

- "오답"보다 "4번째 획 순서가 달랐어요"가 더 유용하다.

### 원칙 4: 게임화는 코어 학습을 방해하지 않아야 한다

- 미니게임은 별도 모드로 붙인다.
