# 2026-09-15 화요일 — 읽기 퀴즈

## 소재 근거

- 실제 DB의 `人` 상세 데이터에 대표 단어 `人気（にんき）— 인기`가 등록되어 있음.
- 앱에서 가능한 학습 흐름: `人` 검색 → 상세 화면의 대표 단어 확인 → 획순 보기 → 직접 써 보기.
- 최근 소재 `梅雨`, `注`, `永`, `習`, `選`과 중복되지 않음.

## Threads

읽기 퀴즈 📖

「この店は人気があります。」
여기서 人気의 읽기는?

① ひとき  ② にんき  ③ じんき

정답은 ② にんき.
뜻은 ‘인기’예요.

人을 혼자 보면 ひと가 먼저 떠오르지만,
人気에서는 にんき로 읽습니다.
아는 한자도 단어가 되면 읽기가 달라져서 자주 헷갈려요.

서당에서는 人을 검색한 뒤
상세 화면에서 人気（にんき）를 확인하고,
획순을 본 다음 직접 써 보며 연결할 수 있어요. ✍️

## 권장 실제 앱 장면

`人` 상세 화면에서 대표 단어 `人気（にんき）`가 보이도록 캡처. 가능하면 이어서 획순 화면과 직접 쓰기 화면을 짧게 녹화해 후속 릴스로 재사용한다.
