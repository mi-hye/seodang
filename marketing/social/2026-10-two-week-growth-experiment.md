- **제안:** 실행 시각과 대화 연결은 유지한다. 10월 1~14일에는 X 게시·팔로우·후보 조사를 중단하고, Instagram 릴스와 Threads 문제형 글에 집중한다. X 캠페인 링크 이름만 예약하고 실제 배포는 하지 않는다.

- 실험 기간에는 팔로우 후보 조사와 실제 팔로우도 진행하지 않는다. 시간과 측정 범위를 콘텐츠 제작·게시·성과 분석에 집중한다.
- 게시물 공개는 현재 하트비트의 최종 버튼 사용자 확인 규칙을 유지한다. 사용자가 특정 게시물의 공개를 직접 요청한 경우에는 그 요청을 따른다.

## 실제 제품 기능과 문구 경계

- `app/practice/[characterId].tsx`: 해당 한자를 열어 획 가이드를 켜고 끄며 직접 쓴 뒤 제출한다.
- `src/domain/practice/evaluatePractice.ts`, `app/practice/result.tsx`: 제출 후 점수와 획수·방향 등 피드백을 보여주고 다시 연습할 수 있다. “70점 넘기”는 사용자가 도전 목표로 삼을 수 있으나 앱의 공식 합격선이라고 말하지 않는다.
- `app/daily-reading.tsx`: 오늘의 독해를 읽고 번역을 확인할 수 있다. “10초 독해”는 **SNS 게시물의 도전 시간**이며 앱 내 타이머나 독해 퀴즈 기능을 뜻하지 않는다.
- 앱 내 퀴즈·자동 오답 퀴즈·자동 다음 날 재도전 알림을 홍보하지 않는다. 다음 날에는 사용자가 같은 한자를 다시 찾아 직접 써보는 행동을 제안한다.
- 실제 화면을 녹화한 영상만 사용한다. 점수·피드백 장면은 실제 쓰기 제출의 결과를 녹화하며 임의의 점수를 합성하지 않는다. “대부분 틀린다” 같은 통계성 훅은 근거가 없으므로 사용하지 않는다.

## 콘텐츠 흐름

1. **짧은 문제:** 첫 1~2초 또는 첫 문장에 정확한 질문을 둔다. 한자·단어·읽기·뜻은 데이터베이스와 일본어 근거로 검증한다.
2. **직접 써보기:** 쓰기 소재는 앱에서 가이드를 보거나 숨기고 직접 쓰는 실제 행동을 보여준다. 독해 소재는 읽고 뜻을 확인하는 기능으로 연결하며 억지로 쓰기를 붙이지 않는다.
3. **점수·피드백:** 쓰기 결과에 실제로 표시된 점수와 피드백을 보여준다. 점수는 개인의 시도 결과이며 앱의 보장 효과가 아니다.
4. **내일 재도전:** 사용자가 같은 글자를 다시 찾아 가이드 없이 써보도록 권한다. 자동 예약 기능으로 표현하지 않는다.

CTA는 소재에 맞게 한 행동만 요청한다. 쓰기 릴스 예: “서당에서 직접 써보고 몇 점이 나왔는지 댓글로 남겨주세요.” 독해형 예: “여러분은 어떻게 읽었나요?” 프로필 링크, 댓글, 저장, 설치를 한 게시물에서 동시에 요구하지 않는다.

App Store Connect에서 `seodang_ig_202610`, `seodang_threads_202610` 캠페인 링크를 각각 **실제 화면에서 생성**한다. 제공자 토큰(`pt`)은 계정 공통이고 캠페인 토큰(`ct`)만 다르게 쓴다. 토큰과 링크를 임의로 만들지 않는다. Instagram은 프로필 링크, Threads는 프로필 또는 게시물 링크에 해당 채널 링크를 배치한다. X는 실험 중 배포하지 않는다.

게시물 조회수와 프로필 방문은 App Store Connect 수치가 아니다. 플랫폼 인사이트에서 따로 기록한다. App Store Connect는 캠페인별 스토어 페이지 조회·첫 다운로드·사용을 보되, 작은 캠페인은 최소 수치와 개인정보 보호 기준 때문에 빈칸일 수 있다. 보유율은 분석 데이터 공유에 동의한 사용자 기준이며 소규모 채널별 D1/D7이 보이지 않을 수 있다. 이 경우 0으로 기록하지 않고 “측정 불가”로 적는다. 링크 클릭이 플랫폼에서 제공되지 않으면 별도 클릭 로그 없이는 정확한 클릭률을 계산하지 않는다.

매일 같은 시각에 게시물별 `조회→프로필 방문→링크 클릭→스토어 페이지 조회→첫 다운로드→D1/D7`을 가능한 범위로 기록한다. 조회 부족은 훅·썸네일·초반 2초, 클릭 부족은 게시물과 프로필의 가치 설명, 스토어 전환 부족은 스토어 스크린샷·문구, 재방문 부족은 첫 쓰기 경험과 다시 연습하는 흐름을 우선 점검한다. 작은 표본에서 단일 게시물의 승패를 확정하지 않고 세 유형의 방향성을 함께 본다. D7까지 성숙한 코호트가 충분해진 뒤에 설치와 재방문 모두 나은 유형만 확대한다.
