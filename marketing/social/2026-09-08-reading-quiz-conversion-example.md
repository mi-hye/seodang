# `梅雨（つゆ）` 읽기 퀴즈 개선 예시

용도: 이미 공개된 게시물을 수정하거나 재게시하기 위한 파일이 아니라, 다음 콘텐츠 작성 때 참고할 로컬 운영 예시다.

내부 판단 메모:

- 방문·다운로드 표본은 아직 작으므로 수치를 게시물에 넣거나 전환 효과를 입증한 것처럼 쓰지 않는다.
- 단순 정답 반응보다 “이 표현을 왜 헷갈리는지”와 “앱에서 무엇을 해볼 수 있는지”를 자연스럽게 연결한다.
- 서당에는 앱 내 퀴즈 기능이 없으므로 퀴즈 풀이·문제 묶음·퀴즈 오답 저장 기능을 암시하지 않는다.

### 개선이 필요한 지점

- `梅雨`에는 실제로 `ばいう`라는 읽기도 있으므로, 문맥 없이 ①을 완전히 틀린 읽기처럼 보이게 하면 모호하다.
- 정답과 뜻까지만 제시되어 학습자가 왜 헷갈리는지, 다음에 무엇을 연습하면 좋은지가 없다.
- 댓글 참여 외에는 서당의 실제 학습 장면으로 이어지는 연결이 없다.

## After

### Threads 문구

오늘의 일본어 읽기 퀴즈 ☔

「梅雨が明ける。」  
이 문장에서 「梅雨」를 가장 자연스럽게 읽으면?

① ばいう  
② つゆ  
③ うめあめ

정답은 ② `つゆ`예요.  
`梅雨が明ける`는 “장마가 끝나다”, `梅雨明け（つゆあけ）`는 “장마 끝”이라는 뜻입니다.

참고로 `ばいう`도 존재하는 읽기예요. `梅雨前線（ばいうぜんせん）`처럼 한자어 느낌의 복합어에서 만날 수 있고, 일상적으로 장마를 말할 때는 보통 `つゆ`를 씁니다.

읽기는 익숙해도 `梅`와 `雨`를 막상 손으로 쓰면 획순이 흐릿해지기 쉬워요. 서당에서 두 한자를 각각 검색해 획순을 본 뒤 한 번씩 직접 써보세요. ✍️

### 붙일 실제 앱 장면

가짜 화면을 만들지 말고 실제 서당 앱 또는 시뮬레이터에서 다음 순서로 녹화한다.

1. 한자 검색에서 `梅` 검색
2. 상세 화면에서 읽기와 `梅雨（つゆ）` 특수 읽기 확인
3. `쓰기 연습 시작` 선택
4. `획 보기`로 실제 획순 애니메이션 확인
5. 사용자가 `梅`를 한 번 직접 쓰는 장면

`雨`는 같은 흐름으로 별도 촬영할 수 있다. 한 영상에 두 글자를 모두 넣어 복잡해지면 그날의 핵심 글자인 `梅`만 보여준다.

## Instagram용 구성 예시

화요일에는 기존 일정상 Instagram 게시물을 준비하지 않는다. 아래는 같은 소재를 월·수·금 콘텐츠로 재활용할 때의 예시다.

### 미디어 1 — 1080×1350 카드

- 상단 훅: `梅雨が明ける。`의 `梅雨`, 어떻게 읽을까요?
- 중앙 보기: `① ばいう  ② つゆ  ③ うめあめ`
- 하단 안내: `정답과 읽기 차이는 캡션에서 확인`
- 서당 로고는 작게 배치하고 설치 문구는 카드에 넣지 않는다.

### 미디어 2 — 실제 앱 세로 영상

- 길이: 6~12초, MP4(H.264), 가능하면 1080×1920
- 0~2초: 검색 결과에서 `梅` 선택
- 2~6초: 상세 화면의 읽기와 `梅雨（つゆ）` 확인
- 6~10초: 쓰기 화면에서 `획 보기` 애니메이션
- 필요하면 획순 구간만 2회 반복하되 가짜 UI·생성형 시연은 사용하지 않는다.

## 운영 체크

- 정답은 게시물·캡션 안에 제공한다.
- `ばいう`가 존재하는 읽기라는 점을 설명해 복수 정답 오해를 막는다.
- 앱 내 퀴즈 기능을 암시하지 않는다.
- 실제 지원 기능인 한자 검색, 상세 읽기, 특수 읽기, 획순 보기, 직접 쓰기만 보여준다.
- CTA는 `서당에서 해당 한자 연습` 하나로 끝낸다. 같은 글에서 댓글·저장·설치를 동시에 요구하지 않는다.
- 이미 공개된 2026-09-08 게시물은 수정하거나 재게시하지 않는다.
