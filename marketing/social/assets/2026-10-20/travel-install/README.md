# 2026-10-20 여행 전 편의점 회화 · 발행 준비

상태: 준비·검수 완료. 아직 미발행·미예약. Instagram, Threads, X 각각 게시물 하나에 한국어 영상 먼저, 일본어 영상 다음 순서로 첨부한다.

## 파일

- seodang-konbini-ko.mp4: 한국어 사용자에게 일본어 학습 소개
- seodang-konbini-ja.mp4: 일본어 사용자에게 한국어 학습 소개
- instagram-threads-caption.txt: 두 언어가 함께 들어간 본문
- x-caption.txt: 두 언어가 함께 들어간 짧은 본문

## 구성

첫 3초: 여행지 계산대에서 아는 말이 안 나오는 상황.
중간: 10/19에 녹화한 실제 학습 플레이를 재편집. 새 촬영이나 새 기능 소개가 아니다.
마지막 5초: 프로필에서 다운로드 → 학습 언어 선택 → 해당 편의점 학습 이름 안내.

현재 앱의 배포 오디오를 사용한다. 한국어 사용자 영상은 VOICEVOX Nemo 男声1, 일본어 사용자 영상은 Supertonic3 M1. 원본은 전날 published-audio의 검증된 M4A이며, 앱과 동일하게 0.8배속·피치 유지. 도입/마무리는 자막이며 추가 내레이션 없음.

실제 앱의 sentence-state.js, korean-state.js에서 학습 이름을 확인했다. 설치 또는 음성 발화만으로 회화 실력이 보장된다는 표현은 사용하지 않는다. 음성 인식 기능을 보여주는 영상이 아니다.

## 발행 때

두 파일을 하나의 게시물에 순서대로 첨부. 기존 공개 스토어 프로필 링크를 안내한다. 비공개 체험 Site는 연결하지 않는다. X 프로필은 현재 iOS 링크만 있으므로 양쪽 OS 링크가 있다는 문구는 쓰지 않는다. 기존 10/19 게시물과는 별도 소재이며 삭제하지 않는다. 합성 음성·이미지 공개 표시는 플랫폼 지원 여부에 맞춰 적용한다.

## 관찰할 지표

게시 후 동일한 관측 기간을 기록하며 프로필 방문, 외부 링크 클릭, 스토어 방문, 실제 다운로드를 구분한다. 프로필 공용 링크를 통해 발생한 설치는 이 게시물의 설치라고 단정하지 않는다. 현재 게시물 단위 설치 추적은 연결되어 있지 않다.
