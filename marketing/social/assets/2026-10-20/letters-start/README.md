# 10/20 글자 입문 · 이미지 게시물

현재 요청: 영상 대신 한국어 이미지 1장 + 일본어 이미지 1장과 양국어 본문 준비. 각 채널 한 게시물에 01-ko.png, 02-ja.png 순으로 첨부한다. 아직 발행·예약하지 않았다.

한국어 사용자에게 일본어 글자부터 상황별 회화 학습을, 일본어 사용자에게 한글 구조와 발음부터 상황별 회화 학습을 소개한다. Instagram·Threads 본문과 X 짧은 본문은 각 txt에 있다.

도구: built-in image_gen. 프롬프트는 image-prompts.txt. 앱의 현재 로컬 학습 렌더러로 화면을 캡처했고 해당 이미지를 생성 도구의 합성 참조로 제공했다. 최종 이미지는 AI가 생성한 여행 배경·폰 합성 광고 이미지이므로 앱의 원본 스크린샷 파일과 구분한다. 학습 내용은 screenshot 참조와 대조한다. 허위 무료/유창성/학습시간 보장 없음.

기존 station-meeting 영상은 보관하되 내일 게시 대상으로 사용하지 않는다. 여행 물 주문 초안도 재사용하지 않는다. 프로필 기존 공개 스토어 링크 안내; 비공개 Site 링크 미사용. X 프로필 iOS만 있으므로 두 스토어 링크 제공을 주장하지 않는다.
