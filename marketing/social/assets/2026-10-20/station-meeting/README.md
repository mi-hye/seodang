# 10/20 역에서 친구 만나기 · 수정본

한국어 영상 → 일본어 영상 순서로 Instagram, Threads, X 각각 한 게시물에 두 파일을 첨부한다. 아직 발행하거나 예약하지 않았다.

물 두 병 주문은 10/19에 이미 발행한 소재라 제외했다. travel-install 초안은 폐기 대상이며 이 폴더가 최신본이다.

새로운 내용: 일본어로 개찰구 앞에서 기다린다고 말하기 / 한국어로 출구 앞에서 기다린다고 말하기. 역 약속이라는 문제 → 실제 학습 화면 → 설치 후 학습 이름 안내.

기존 앱의 학습 렌더러와 상태 처리 코드를 사용한 로컬 촬영용 복사본에서 직접 클릭하며 각 단계를 새로 캡처해 편집했다. 연속 실시간 녹화가 아닌 화면 전환 편집 영상이다. 앱 본체나 공개 체험 사이트는 수정하지 않았다. 원본 캡처는 ko-frames, ja-frames와 각 capture.json에 있다.

음성은 현재 catalog.json의 meet-wait와 korean.3-3.1 M4A를 다운로드하고 SHA256을 대조했다. 0.8배속·피치 유지. 도입 3초와 마지막 5초는 자막이며 추가 내레이션이 없다.

설치 안내는 기존 프로필 스토어 링크를 사용한다. 비공개 체험 사이트를 연결하지 않는다. X 프로필에는 현재 iOS 링크만 있다. 특정 게시물에서 설치까지의 개별 추적은 현재 불가능하므로 프로필 방문·스토어 방문·다운로드를 구분해 관찰한다.
