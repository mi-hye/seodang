# 2026-10-21 · 배운 말을 써보는 교류

준비 상태. 발행·예약하지 않음. 한국어(일본어 학습) → 일본어(한국어 학습) 이미지 2장을 각 채널 한 게시물에 첨부. Instagram·Threads 공통 본문, X 축약 본문 사용.

오늘의 여행·글자 입문 소재와 달리, 배운 언어를 사용해볼 공간을 안내한다. 설치 동선: 프로필 스토어 링크 → 앱 다운로드 → 교류/交流 → 최초 이용 시 닉네임 등 프로필 입력 및 약속 동의 → 짧은 자기소개 작성. 이미 설치한 사람도 같은 교류 메뉴에서 시작 가능.

기능 확인: prototype/src/community.js (글·사진, 댓글, 표현 도움 요청), community-copy.js (한국어·일본어 메뉴 이름), app.js (교류/交流 탭). 최신 기능 제공에 대한 사용자 인계를 바탕으로 준비. 스토어별 버전 번호는 이번 제작에서 별도로 검증하지 않았으므로 본문에 쓰지 않는다.

광고 이미지는 개념 일러스트이며 실제 화면 캡처나 이용자 후기가 아니다. 자기소개 문장은 예시로 표시. 원어민 답변, 즉시 매칭, 첨삭 보장, 이용자 수를 주장하지 않는다.

제작: built-in image_gen. 최종 프롬프트는 image-prompts.txt. 발행 승인 필요.

## 실제 사용 화면 반영 수정
실제 community.js의 mountCommunity 컴포넌트를 원본 CSS와 함께 로컬 렌더링하고 CUA로 자기소개 문장을 입력하여 screen-ko.png·screen-ja.png를 캡처했다. 운영 API 대신 로컬 데모 프로필을 주입했으며 실제 사용자 데이터/게시물은 사용하지 않았다. 공개 게시하지 않은 작성 예시다. 스토어 설치본 직접 촬영은 아니다. capture.html은 마케팅 전용 캡처 파일이며 앱 코드 변경 없음. 이미지 안에 앱 화면·작성 예시 표시, 본문은 기존 유지.

최종 첨부 파일: 01-ko-v2.png → 02-ja-v2.png. 이전 01-ko.png·02-ja.png는 보관본. 원본 화면을 image_gen 합성에 사용했으므로 최종 광고는 캡처 기반 합성이며 픽셀 그대로의 원본 캡처는 screen-ko.png·screen-ja.png. 프롬프트 image-prompts-v2.txt.
